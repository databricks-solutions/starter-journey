# 1. Introduction

> **You'll map** the platform layers you need to build, in the order they depend on each other, in ~10 min.
>
> **Prereqs:** [A Databricks account](https://docs.databricks.com/aws/en/getting-started/free-trial)

Start with the foundation.
Every dashboard, model, and agent reads data from the same platform and catalog.
If the tables are wrong, reports mislead, models train on noise, and agents return unreliable answers.

BI, machine learning, and AI have different serving needs.
They still depend on the same account, governance model, and trusted data.
Fix those layers once, then build each workload on top.

This guide follows that dependency order.
It starts with the account and workspaces, moves through data access and governance, then reaches the products people use.
Operations closes the loop by making the platform repeatable.
