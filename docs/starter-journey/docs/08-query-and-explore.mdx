# 8. Query and explore

> **You'll create** a serverless SQL warehouse and save a daily franchise revenue query in ~15 min.
>
> **Prereqs:** [Build the first ETL pipeline](/docs/07-build-first-pipeline/)

## The big picture

The pipeline has written clean transaction and franchise tables. You need a query engine and a concrete question: how much revenue did each franchise make each day?

Create a small serverless SQL warehouse first. Use it to answer that question. Keep the warehouse after this walkthrough. Section 9 uses the same query gateway for business-facing analytics.

## Answer a business question

The silver tables are ready. Use them to answer: How much revenue did each franchise make each day?

<StepGuide
  description="Ask Genie Code for the join, check its work, run it, and save the query."
  minutes={10}
  idPrefix="query-step"
  referenceHref="https://docs.databricks.com/aws/en/sql/user/sql-editor/write-queries"
  referenceLabel="Write queries in the SQL Editor (Databricks docs)">

<Step>

In the workspace sidebar, click **SQL Editor**, then under **Create new** select **SQL Query**.

<StepImage src="/img/query-and-explore/query_1.png" alt="SQL Editor in the sidebar with the Create new SQL Query option" />

</Step>

<Step>

Open the warehouse selector in the top right, then click **More**.

<StepImage src="/img/query-and-explore/query_2.png" alt="Warehouse selector open with the More option" />

</Step>

<Step>

In **Attach to an existing compute resource**, select `starter_journey_wh`, then click **Start and attach**.

<StepImage src="/img/query-and-explore/query_3.png" alt="Attach to an existing compute resource dialog with starter_journey_wh selected" />

</Step>

<Step>

Set the catalog and schema to the ones from your pipeline (`starterjourney_catalog` and `bakehouse_silver`).

<StepImage src="/img/query-and-explore/query_4.png" alt="SQL Editor attached to starter_journey_wh with the starterjourney_catalog catalog and bakehouse_silver schema selected" />

</Step>

<Step>

Open Genie Code and paste this prompt:

<PromptBlock>
Using the `transactions` and `franchises` tables in the current `bakehouse_silver` schema, write a query that joins them on `franchise_id`. Return the transaction date, franchise name, and total daily revenue. Calculate daily revenue as the sum of `total_price`, group by transaction date and franchise name, and sort by transaction date and franchise name.
</PromptBlock>

<StepImage src="/img/query-and-explore/query_5.png" alt="Genie Code panel with the daily franchise revenue prompt pasted" />

</Step>

<Step>

Review the generated SQL, then click **Accept**:

- `transactions` joins to `franchises` on `franchise_id`.
- `transaction_timestamp` is converted or truncated to a calendar day.
- `total_price` is summed.
- The query groups by transaction day and franchise name.

<StepImage src="/img/query-and-explore/query_6.png" alt="Genie Code generated SQL with the Accept button" />

<details>
<summary>Use the fallback SQL</summary>

Generated SQL can look different and still be correct. If it misses one of the checks, replace it with:

```sql
SELECT
  DATE(t.transaction_timestamp) AS transaction_date,
  f.franchise_name,
  SUM(t.total_price) AS daily_revenue
FROM transactions AS t
INNER JOIN franchises AS f
  ON t.franchise_id = f.franchise_id
GROUP BY
  DATE(t.transaction_timestamp),
  f.franchise_name
ORDER BY
  transaction_date,
  franchise_name;
```

</details>

</Step>

<Step>

Click **Run all**, or press Cmd+Enter on macOS or Ctrl+Enter on Windows and Linux.

<StepImage src="/img/query-and-explore/query_7.png" alt="SQL Editor with the Run all button" />

</Step>

<Step>

Check that the grid contains `transaction_date`, `franchise_name`, and `daily_revenue`. Franchise names should not be null, and the result should contain more than one date and franchise combination.

<StepImage src="/img/query-and-explore/query_8.png" alt="SQL Editor results with transaction_date, franchise_name, and daily_revenue columns" />

</Step>

<Step>

Save the query. Use Genie's **Suggest a title** to name it.

<StepImage src="/img/query-and-explore/query_9.png" alt="Saving the query and using Suggest a title to name it" />

</Step>

</StepGuide>

## Where people trip

<details>
<summary>The editor cannot find the silver tables</summary>

Selecting `bakehouse_silver` is not enough if the editor is using another catalog. Select `starterjourney_catalog`, then select `bakehouse_silver` again.
</details>

<details>
<summary>The SQL runs but answers a different question</summary>

Check the join on `franchise_id`, the day-level conversion of `transaction_timestamp`, and `SUM(total_price)`. A valid query needs all three.
</details>

<details>
<summary>The warehouse does not reach Running</summary>

Confirm that Serverless SQL warehouses are available in the workspace. Do not switch warehouse types during the walkthrough because startup and cost behavior will differ.
</details>
