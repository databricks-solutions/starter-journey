# 9. Unified Analytics

> **You'll understand** how one governed metric view feeds both a dashboard and a Genie Agent, so every surface returns the same number.
>
> **Prereqs:** [7. Build the first ETL pipeline](/docs/03-data-access-etl/build-first-pipeline/), [8. Query and Explore](/docs/03-data-access-etl/query-and-explore), [Unity Catalog foundations](/docs/01-introduction/foundations/unity-catalog)

## The call

Define the number once, then present it two ways.

Your silver tables are not the finish line. Business users need consistent numbers, and they need to reach those numbers without writing SQL. So define each KPI one time as a Unity Catalog metric view. A dashboard gives people a fixed view they can trust. A Genie Agent answers the follow-up questions a dashboard can't anticipate. Both read the same metric view, so the number cannot drift between them.

![Databricks Data Intelligence Platform diagram with four layers highlighted: tables in purple, business semantic layer in red, data warehousing in orange, and AI/BI in green.](/img/unified-analytics.jpg)

| Highlight | Layer | What it is |
|---|---|---|
| Purple | Tables | The medallion bronze and silver tables your pipeline produced. Every query in the serving layer reads from here. |
| Red | Business semantic layer | Where you define KPIs once, on top of the tables. Unity Catalog metric views live here. |
| Orange | Data warehousing | Every AI/BI tool reaches the data through a SQL warehouse. The warehouse is the single query gateway. |
| Green | AI/BI | Dashboards and Genie. The surfaces business users interact with. Both read the metric view through the warehouse. |

## Why define it once

- One object, one number. Dashboards, Genie, and SQL all read the same metric view, so a KPI can't come back different per tool.
- Governed in the catalog. Access, lineage, and certification travel with the metric because it's a Unity Catalog object.
- Short debug path. When a number looks wrong, you check one definition, not every dashboard and prompt that copied it.
