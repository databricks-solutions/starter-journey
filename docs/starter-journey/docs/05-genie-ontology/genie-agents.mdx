# Genie Agents

> **You'll create and share** the Bakehouse Sales Assistant, a natural-language agent on your metric view, in ~15 min.
>
> **Prereqs:** [Dashboards](/docs/05-genie-ontology/dashboards)

## The big picture

A dashboard answers the questions you anticipated. A Genie Agent answers the ones you didn't. Point it at the same `franchise_sales_metrics` metric view, and business users can ask in plain English, "which franchise sells the most?", and get the same numbers the dashboard shows.

## Build the agent

<StepGuide
  description="Create a Genie Agent on the metric view, tune it, validate an answer, and share it."
  minutes={15}
  idPrefix="genie-step"
  referenceHref="https://docs.databricks.com/aws/en/genie-agents/set-up"
  referenceLabel="Create and manage a Genie Agent (Databricks docs)">

<Step>

Click **Genie Agents** in the workspace sidebar, then **New** in the upper-right corner.

<StepImage src="/img/unified-genie-agents/1.png" alt="Genie Agents list with the New button in the upper-right corner" />

</Step>

<Step>

In the **Connect your data** dialog, browse to `starterjourney_catalog` > `bakehouse_gold`, select `franchise_sales_metrics`, then click **Create**.

The metric view already carries the join and the franchise field, so you don't need to add the silver tables separately.

<StepImage src="/img/unified-genie-agents/2.png" alt="Connect your data dialog with franchise_sales_metrics selected under bakehouse_gold" />

</Step>

<Step>

Click **Configure**, then edit the **About this agent** panel. Set the **Name** to `Bakehouse Sales Assistant` and the **Default warehouse** to `starter_journey_wh`, then click **Save**.

<StepImage src="/img/unified-genie-agents/3.png" alt="Edit agent details dialog with the name Bakehouse Sales Assistant and the starter_journey_wh warehouse" />

</Step>

<Step>

On the **About** tab, edit the **Description** to explain what the agent does, its capabilities, and its limitations, then click **Save**.

<StepImage src="/img/unified-genie-agents/4.png" alt="Edit description dialog describing the agent capabilities and limitations" />

</Step>

<Step>

Open the **Instructions** tab and add general instructions so the agent speaks your business language. Paste this, then click **Save**:

<PromptBlock>
"Sales" and "revenue" both mean Total Sales. Use Sales Date as the time dimension for any trend or over-time question. Franchise means the franchise name. When asked for the top or best franchise, rank by Total Sales.
</PromptBlock>

<StepImage src="/img/unified-genie-agents/5.png" alt="Instructions tab with the general instructions pasted" />

</Step>

<Step>

On the **About** tab, edit **Common questions** and add a few so users know what to ask:

- Which franchise had the highest total sales?
- What are total sales by product?
- Show total sales by day.

<StepImage src="/img/unified-genie-agents/6.png" alt="Edit common questions dialog with the three questions added" />

</Step>

<Step>

Ask a validation question in the chat: **Which franchise had the highest total sales?** Confirm the top franchise matches the bar chart on your dashboard.

<StepImage src="/img/unified-genie-agents/7.png" alt="Genie answer naming Baked Bliss as the top franchise by total sales" />

</Step>

<Step>

Click **Share**. Add your audience (for example the `data-analysts-starter-journey` group), set a permission level of at least CAN RUN, and copy the link.

Genie Agents are workspace objects. There is no separate publish button: sharing is how you release the agent.

<StepImage src="/img/unified-genie-agents/8.png" alt="Sharing dialog for Bakehouse Sales Assistant with the data-analysts-starter-journey group and Copy link" />

</Step>

</StepGuide>

## Verify

- The validation answer names the same top franchise as the dashboard's franchise bar chart.
- A shared user with SELECT on the metric view can open the agent and get an answer, not an empty result.

## Where people trip

<details>
<summary>Genie is unavailable or greyed out</summary>

Partner-powered AI features must be enabled at the account and workspace level. An account admin controls this.
</details>

<details>
<summary>A shared user gets an empty answer</summary>

Data access uses the viewer's own Unity Catalog identity. Grant them SELECT on `franchise_sales_metrics` and its source tables.
</details>

<details>
<summary>The answer disagrees with the dashboard</summary>

Both read the same metric view, so check the question's time window and any filters. Add an instruction if Genie keeps reaching for the wrong field.
</details>
