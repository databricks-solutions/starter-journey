# 7. Build the first ETL pipeline

> **You'll build** your first Spark Declarative Pipeline with Genie Code in ~10 min.
>
> **Prereqs:** [Access your data](/docs/06-access-your-data)

<StarterJourneyProgress currentLevel={4}/>

## Build a pipeline with Genie Code

<StepGuide
  description="Follow along in the Workspace. Every step links to itself, so you can send someone straight to the one they are stuck on."
  minutes={10}
  referenceHref="https://docs.databricks.com/aws/en/ldp/"
  referenceLabel="Create a pipeline (Databricks docs)">

<Step>

Go to Jobs & Pipelines > Create > ETL pipeline

<StepImage src="/img/pipeline-etl-1.png" placeholder="Step 1: Jobs & Pipelines › Create › ETL pipeline" />

</Step>

<Step>

Name the pipeline `bakehouse_e2e_pipeline` and choose Python or SQL

<StepImage src="/img/pipeline-etl-2.png" placeholder="Step 2: name and language" />

</Step>

<Step>

Set the destination catalog to `starterjourney_catalog` and the default schema to `bakehouse_bronze`

<StepImage src="/img/pipeline-etl-3.png" placeholder="Step 3: destination catalog starterjourney_catalog and default schema bakehouse_bronze" />

</Step>

<Step>

Open the Genie Code panel in the Pipelines Editor. Ask it to land the two Bakehouse source tables in the bronze schema, then publish cleaned silver tables into a separate silver schema.

<StepImage src="/img/pipeline-etl-4.png" placeholder="Step 4: open Genie Code and enter the prompt" />

<PromptBlock>
Build a medallion pipeline from samples.bakehouse. Land the raw tables in bakehouse_bronze schema, then create silver tables with cleaned column names, typed timestamps, and expectations that drop rows with null primary keys and land them on bakehouse_silver schema.
</PromptBlock>

</Step>

<Step>

Review the plan and code diff Genie Code shows, then click Accept all

<StepImage src="/img/pipeline-etl-5.png" placeholder="Step 5: review the diff and Accept all" />

</Step>

<Step>

Click Start / Run pipeline to validate it end-to-end

<StepImage src="/img/pipeline-etl-6.png" placeholder="Step 6: run the pipeline" />

</Step>

<Step>

Confirm both the bronze and silver schemas were created with their tables, then inspect the pipeline DAG graph.

:::tip
Section 8 and the section 9 metric view read these silver columns by name: `transaction_timestamp` and `total_price` on `transactions`, and `franchise_id` plus `franchise_name` on `franchises`. If Genie Code named them differently, rename them now.
:::

<StepImage src="/img/pipeline-etl-7a.png" placeholder="Step 7: bronze and silver schemas with their tables in Catalog Explorer" />

<StepImage src="/img/pipeline-etl-7b.png" placeholder="Step 7: pipeline DAG graph" />

</Step>

</StepGuide>

## SDP reference material

Awesome pages to have open while you build:

- [Load data in pipelines](https://docs.databricks.com/aws/en/ldp/load), which covers [AutoLoader](https://docs.databricks.com/aws/en/ingestion/cloud-object-storage/auto-loader/) for incremental ingestion from cloud object storage.
- [Transform data with pipelines](https://docs.databricks.com/aws/en/ldp/transform): when to reach for views, materialized views, or streaming tables.
- [Manage data quality with expectations](https://docs.databricks.com/aws/en/ldp/expectations) for constraints and business rules.
- **Python:** [Python language reference](https://docs.databricks.com/aws/en/ldp/developer/python-ref) | [Develop SDP with Python](https://docs.databricks.com/aws/en/ldp/developer/python-dev)
- **SQL:** [SQL language reference](https://docs.databricks.com/aws/en/ldp/developer/sql-ref) | [Develop SDP with SQL](https://docs.databricks.com/aws/en/ldp/developer/sql-dev)
