# 7. Build the first ETL pipeline

> **You'll learn** how Lakeflow and Spark Declarative Pipelines work and build your first transformation pipeline in ~20 min.
>
> **Prereqs:** [Access your data](/docs/06-access-your-data)

## Why this matters

Raw data in storage answers nothing on its own. The job of a pipeline is to turn it into clean tables that an analyst or a dashboard can actually trust. On Databricks you do that with Spark Declarative Pipelines (SDP): you declare what the tables should look like, and the engine works out how to build them and how to keep them up to date as new data lands.

The payoff of "declarative" is that you stop hand-writing the plumbing. You no longer maintain checkpoints by hand or work out which rows are new. You describe the result, and the engine handles incremental processing and dependency order for you.

## How it works: Spark Declarative Pipelines

SDP is the Databricks implementation of [Apache Spark Declarative Pipelines](https://spark.apache.org/docs/latest/declarative-pipelines-programming-guide.html). You write Python (PySpark) or SQL declarations. The engine reads them, works out the execution plan and the order tables depend on each other, and runs the whole thing incrementally.

What that gets you in practice:

- One pipeline can stream from Kafka, batch-load from cloud storage, and query an external database at the same time. You do not split that across three jobs.
- It tracks what has changed and reprocesses only the new or modified rows. On a large table that is the difference between a few minutes and a full rebuild.
- Data quality lives in the code. You write expectations (constraints and business rules) next to the transformation, and rows that fail get quarantined or flagged without extra wiring.
- Every table, view, and pipeline is governed by Unity Catalog, so the permissions and lineage you already set up still apply.

## Create the first pipeline

There are two ways to build it. Pick by where you are right now, not by which is "better."

- **[Workspace + Genie Code](/docs/07-build-first-pipeline/workspace-databricks-agent)**: build interactively in the browser. Start here when you are still figuring out the transformation.
- **[DABs](/docs/07-build-first-pipeline/dabs)**: deploy a full medallion pipeline as code. Reach for this once the shape is settled and you want it reproducible.
