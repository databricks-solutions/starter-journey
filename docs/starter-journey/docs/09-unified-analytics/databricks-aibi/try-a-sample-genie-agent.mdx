# Hands-on lab

> **You'll install** the **AI/BI: Analytics in Capital Markets** dbdemo so you can explore a pre-built Genie Agent and dashboard on sample financial-services data in ~10 min.

## The big picture

A working Genie Agent ("DBDemos - AI-BI - Portfolio Assistant") with a companion AI/BI dashboard and notebook, all loaded with sample portfolio holdings, market sentiment, and stock data. You get to test natural-language questions like *"What is the market sentiment for companies in my portfolio in the retail industry?"* without modeling any of your own data first.

**Official source (Demo Center):** [Demo Center: Data Warehouse and AI/BI](https://www.databricks.com/resources/demos/tutorials?itm_data=demo_center#data-warehouse-and-bi)

<Step>

Install the demo from the dbdemos library. Run these cells in a new Python notebook.

```python
%pip install dbdemos
```

```python
dbutils.library.restartPython()
```

```python
import dbdemos
import random

catalog = 'MY_CATALOG'
schema = 'MY_SCHEMA'

demos_availables_for_genie = ['aibi-portfolio-assistant', 'aibi-customer-support', 'aibi-patient-genomics', 'aibi-marketing-campaign', 'aibi-sales-pipeline-review', 'aibi-supply-chain-forecasting']

demo_to_install = random.choice(demos_availables_for_genie)

dbdemos.install(demo_to_install, catalog=catalog, schema=schema)
```

Swap `MY_CATALOG` and `MY_SCHEMA` for any UC catalog and schema where your user has **CREATE** privileges.

## Verify

Open **Genie Agents** in the workspace nav and check that **DBDemos - AI-BI - Portfolio Assistant** is there. Click in and try one of the suggested questions. You should get an answer with a result table, not an error.

![DBDemos AI-BI Portfolio Assistant Genie Agent landing page with suggested questions](/img/aibi-portfolio-genie.png)

## Where people trip

<details>
<summary>ModuleNotFoundError: dbdemos</summary>

You imported before installing. Run `%pip install dbdemos`, then `dbutils.library.restartPython()`, and only then import.

</details>

<details>
<summary>Permission denied writing catalog or schema</summary>

Your user can't create tables there. Pick a catalog and schema where you can, or ask a metastore admin to grant **CREATE**.

</details>

<details>
<summary>Install hangs</summary>

The cluster can't reach PyPI or is out of resources. Confirm it has internet egress and enough capacity.

</details>
