# Foundations

> **You'll learn** the three building blocks of every Databricks deployment in ~15 min.
>
> **Prereqs:** none

## The big picture

Three concepts hold up every Databricks deployment: the account console, the workspace, and Unity Catalog. Learn them now. Get one wrong and you'll be paying to unwind it after resources are already running, which is the expensive time to find out.

## Databricks Cheatsheet 2026

This reference covers the full Databricks product surface in one document. Everyone contributing to the project should read it before infrastructure work starts.

## Databricks core concepts

Work through these in order. Each one builds on the last.

- **[Account Console](/docs/02-before-you-start/foundations/account-console)**: the central admin portal where you manage workspaces, users, and billing.
- **[Workspace](/docs/02-before-you-start/foundations/workspace)**: the environment where teams build and run data and AI workloads.
- **[Unity Catalog](/docs/02-before-you-start/foundations/unity-catalog)**: the governance layer for all data and AI assets.
- **[Recap and learning](/docs/02-before-you-start/foundations/recap-and-learning)**: quick-check questions to confirm the core concepts landed.
