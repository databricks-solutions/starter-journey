# 14. MLOps

> **You'll** connect the full ML lifecycle on Databricks — features, training, Model Serving, batch and streaming inference, and shipping it all as a Declarative Automation Bundle — so a notebook experiment can reach governed production.
>
> **Prereqs:** [7. Build the first pipeline](/docs/build-first-pipeline/), [Unity Catalog foundations](/docs/before-you-start/foundations/unity-catalog), [13. CI/CD and DevOps](/docs/ci-cd-devops/)

## Why this matters

A model that lives only in a notebook is not in production. The handoff from "it worked on my cluster" to a versioned artifact, a serving endpoint, and monitored inference is where most teams stall. Without MLflow runs, a Unity Catalog model registry, and a repeatable deploy path, you cannot answer which data and code produced the model in prod, who can change it, or when to retrain.

MLOps on Databricks closes that gap on one platform. Features and models sit in Unity Catalog with the same grants and lineage as tables. Training, batch scoring, streaming inference, and deployment automation share Lakeflow Jobs, Model Serving, and Declarative Automation Bundles (DABs) — the same primitives you already use for data pipelines.

## The MLOps lifecycle on Databricks

Work through the stages below in order. Each page is a checkpoint — finish one before you depend on the next in production.

| Stage | What you do | Link |
|---|---|---|
| Feature engineering | Build governed, reusable features in Unity Catalog | [Feature engineering](/docs/mlops/feature-engineering) |
| Model training | Train and track experiments with MLflow; register models in Unity Catalog | [Model training](/docs/mlops/model-training) |
| Model deployment | Serve models through Model Serving endpoints | [Model deployment](/docs/mlops/model-deployment) |
| Inference (batch/streaming) | Score data at rest or in motion; monitor requests with AI Gateway inference tables | [Inference](/docs/mlops/inference) |
| MLOps as code | Ship the lifecycle in a Declarative Automation Bundle (DAB) | [DABs for MLOps](/docs/mlops/dabs) |
