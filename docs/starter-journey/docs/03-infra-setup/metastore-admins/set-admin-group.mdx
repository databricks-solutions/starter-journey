# Set the metastore admin group

> **You'll transfer** metastore ownership to a dedicated admin group in ~5 min.
>
> **Prereqs:** [Add groups](/docs/03-infra-setup/add-groups/manual), with a metastore admin group already created (for example `metastore-admins`)

## The big picture

The metastore is the top-level container for everything in Unity Catalog.
Whoever owns it can manage privileges and transfer ownership of any object inside it.
Give that ownership to a group, not a person, and it survives anyone leaving.

## Prerequisites

- Account-admin access to the Databricks account console.
- A metastore admin group already created (see [Add groups](/docs/03-infra-setup/add-groups/manual)).

:::danger
The metastore owner must be a group.
Assign an individual or a service principal, and the day that person leaves or that principal is deleted, governance operations stop.
:::

## Steps

### 1. Open the account console

Sign in to the account console for your cloud, with your account-admin credentials:

- [AWS](https://accounts.cloud.databricks.com)
- [Azure](https://accounts.azuredatabricks.net)
- [GCP](https://accounts.gcp.databricks.com)

In the left sidebar, click **Catalog**.

<img src={useBaseUrl('/img/set-admin-group/1.png')} alt="Account console home with Catalog in the left sidebar"/>

### 2. Open the metastore

Your metastores are listed by region.
Click the one you want to change.

<img src={useBaseUrl('/img/set-admin-group/2.png')} alt="Metastore list in the account console"/>

### 3. Edit the metastore admin

On the **Configuration** tab, find the **Metastore Admin** section.
It probably shows a system user or one person today.
Click **Edit**.

<img src={useBaseUrl('/img/set-admin-group/3.png')} alt="Metastore Admin section with the Edit button"/>

### 4. Assign the admin group

In the dialog, select your metastore admin group (for example `metastore-admins`) as the admin.
Click **Save**.

<img src={useBaseUrl('/img/set-admin-group/4.png')} alt="Edit Metastore Admin dialog with a group selected"/>

### 5. Turn on auto-assignment

Back on the Configuration tab, confirm **Metastore Admin** now shows your group.
Under **Workspace assignment**, turn on automatic assignment so new workspaces in this region attach to the metastore automatically.

<img src={useBaseUrl('/img/set-admin-group/5.png')} alt="Metastore admin set to a group, with workspace auto-assignment enabled"/>

## Verify

Verification happens in a workspace, not the account console.

1. Open a workspace attached to the metastore.
2. In the left sidebar, click **Catalog**, then the gear icon.
3. Confirm the metastore name shows at the bottom of the menu, and open **External locations**.

<img src={useBaseUrl('/img/set-admin-group/6.png')} alt="Catalog gear menu showing the metastore and External locations"/>

The **Create external location** button is active, and you can see existing external locations, credentials, and connections.
That confirms your group has metastore admin rights.

<img src={useBaseUrl('/img/set-admin-group/7.png')} alt="External Data page with external locations visible and the create button active"/>

## Where people trip

<details>
<summary>Cannot change the metastore owner</summary>

Only the current owner or an account admin can transfer ownership.
Confirm you have account-admin privileges.
If the current owner already left the organization, contact Databricks support.
</details>

<details>
<summary>External locations tab is empty</summary>

An empty External locations or Credentials tab almost always means you are not a member of the metastore admin group.
Check your group membership before going further.
</details>
