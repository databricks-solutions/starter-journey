# Additional dashboards

> **You'll install** the community **`system-tables`** demo so optional AI/BI dashboards run against your real billing data in ~15 min.

## The big picture

A set of AI/BI dashboards and notebooks running on your own billing data: consumption tracking, a **DBU** forecast, model-endpoint cost attribution, warehouse attribution, and UC/volume analysis. The intermediate tables land in a Unity Catalog catalog and schema you pick, which does not have to be `main`.

**Official source (Demo Center):** [System Tables: Billing Forecast, Usage Analytics, and Access Auditing with Unity Catalog](https://www.databricks.com/resources/demos/tutorials/governance/system-tables?itm_data=demo_center&itm_source=www&itm_category=home&itm_page=home&itm_component=card&itm_offer=system-tables)

:::tip

Confirm the demo slug is still **`system-tables`** on PyPI or GitHub before you standardize this in enablement.

:::

## Steps

<StepGuide
  description="Install the system tables demo in a notebook and confirm the generated assets."
  minutes={15}
  referenceHref="https://www.databricks.com/resources/demos/tutorials/governance/system-tables"
  referenceLabel="System Tables demo (Demo Center)">

<Step>

Create a Python notebook and install `dbdemos`:

```python
%pip install dbdemos
```

</Step>

<Step>

Restart Python so the notebook can import the installed package:

```python
dbutils.library.restartPython()
```

</Step>

<Step>

Set `catalog` and `schema` to Unity Catalog assets where you can create tables, then install the demo:

```python
import dbdemos

catalog = "mycatalog"
schema = "myschema"

dbdemos.install("uc-04-system-tables", catalog=catalog, schema=schema)
```

</Step>

<Step>

Wait until the notebook finishes and prints the notebooks, dashboards, and Genie Space it created.

<StepImage src="/img/usage-demo-2.webp" alt="dbdemos install output listing the installed Databricks AI/BI dashboards and Genie Space for system tables" />

</Step>

</StepGuide>

## Where people trip

<details>
<summary>ModuleNotFoundError: dbdemos</summary>

Run `%pip install dbdemos`, then `dbutils.library.restartPython()`, before you import.

</details>

<details>
<summary>Permission denied writing catalog or schema</summary>

Pick a catalog and schema where your user can create tables, or ask a metastore admin to grant **CREATE**.

</details>

<details>
<summary>Permission denied on system tables</summary>

An admin has to grant **SELECT** on **`system.billing`** (and **`system.access`** for the audit-backed tiles).

</details>

<details>
<summary>Empty charts</summary>

New accounts have no history yet. Forecast tiles stay thin until enough daily usage accumulates.

</details>

<details>
<summary>Install hangs</summary>

Confirm the cluster has internet egress to PyPI and enough resources.

</details>
