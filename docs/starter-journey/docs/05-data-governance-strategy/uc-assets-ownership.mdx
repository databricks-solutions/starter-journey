# Assign ownership of Unity Catalog assets

> **You'll transfer** ownership of your Unity Catalog assets (credentials, external locations, connections, catalogs, and schemas) to the admin group and grant working permissions, in ~15 min.
>
> **Prereqs:** [Plan your groups](/docs/05-data-governance-strategy/groups) and [set the metastore admin group](/docs/03-infra-setup/metastore-admins/set-admin-group)

## The big picture

Every Unity Catalog asset has an owner.
The owner can manage the asset and grant others access to it.
You change ownership in two places: first-level securables (storage credentials, external locations, connections) and catalog children (catalogs and their schemas).
Both are done from Catalog Explorer inside a workspace.

## Prerequisites

- Access to a workspace attached to the metastore.
- Owner, metastore admin, or account admin rights on the assets you are changing.
- The target admin group already exists (see [Set admin group](/docs/03-infra-setup/metastore-admins/set-admin-group)).

:::warning
An empty External locations or Credentials tab almost always means you are not a member of the metastore admin group.
Check your group membership before going further.
:::

## Transfer first-level securables

Storage credentials, external locations, and connections all follow the same flow.
These steps use a storage credential.
Repeat them for each external location and connection.

<StepGuide
  description="Follow the ownership and permissions flow for a storage credential, then repeat it for external locations and connections."
  minutes={10}
  idPrefix="first-level-securable-step"
  referenceHref="https://docs.databricks.com/aws/en/data-governance/unity-catalog/manage-privileges/"
  referenceLabel="Manage Unity Catalog privileges (Databricks docs)">

<Step>

In the workspace left sidebar, click **Catalog**.
Click the gear icon, then choose **Credentials**.
The same menu holds **External locations** and **Connections**.

<StepImage src="/img/uc-assets-ownership/1.png" alt="Catalog gear menu with Credentials, External locations, and Connections" />

</Step>

<Step>

On the **Credentials** tab, click the credential whose owner you want to change.

<StepImage src="/img/uc-assets-ownership/2.png" alt="Credentials tab with a storage credential" />

</Step>

<Step>

On the **Overview** tab, find the **Owner** field under **About this credential** and click the edit icon (pencil).

<StepImage src="/img/uc-assets-ownership/3.png" alt="Credential overview with the owner edit icon" />

</Step>

<Step>

Enter your admin group (for example `fe-vending-metastore-admins`) as the owner.
Click **Save**.

<StepImage src="/img/uc-assets-ownership/4.png" alt="Set owner dialog with the admin group selected" />

</Step>

<Step>

The **Owner** field now shows the admin group.

<StepImage src="/img/uc-assets-ownership/5.png" alt="Credential owner set to the admin group" />

</Step>

<Step>

Ownership lets the group manage the asset.
Grant the privileges the people who use it need.

Open the **Permissions** tab and click **Grant**.

<StepImage src="/img/uc-assets-ownership/6.png" alt="Permissions tab with the Grant button" />

</Step>

<Step>

Select the principal (for example `data-scientist`).
Select the privileges to grant, then click **Confirm**.

<StepImage src="/img/uc-assets-ownership/7.png" alt="Grant dialog with a principal and privileges selected" />

</Step>

<Step>

The **Permissions** tab lists the privileges you granted.

<StepImage src="/img/uc-assets-ownership/8.png" alt="Permissions tab listing the granted privileges" />

</Step>

</StepGuide>

Repeat steps 1 to 8 for each external location and connection.

## Transfer catalogs and schemas

Catalogs and their schemas follow the same owner-then-permissions flow.
These steps use a catalog.
Repeat them for each schema.

<StepGuide
  description="Transfer a catalog to the admin group, grant working permissions, then repeat the flow for its schemas."
  minutes={5}
  idPrefix="catalog-schema-step"
  referenceHref="https://docs.databricks.com/aws/en/data-governance/unity-catalog/manage-privileges/"
  referenceLabel="Manage Unity Catalog privileges (Databricks docs)">

<Step>

In the left sidebar, click **Catalog**, then click the catalog in the tree.
On the **Overview** tab, find the **Owner** field under **About this catalog** and click the edit icon (pencil).

<StepImage src="/img/uc-assets-ownership/9.png" alt="Catalog overview with the owner edit icon" />

</Step>

<Step>

Enter your admin group as the owner.
Click **Save**.

<StepImage src="/img/uc-assets-ownership/10.png" alt="Set owner dialog for the catalog with the admin group selected" />

</Step>

<Step>

Open the **Permissions** tab and click **Grant**.

<StepImage src="/img/uc-assets-ownership/11.png" alt="Catalog permissions tab with the Grant button" />

</Step>

<Step>

Select the principal.
Pick a privilege preset (for example **Data Editor**) or select privileges by hand, then click **Confirm**.

<StepImage src="/img/uc-assets-ownership/12.png" alt="Grant dialog with the Data Editor preset selected" />

</Step>

<Step>

The **Permissions** tab lists the privileges you granted.
Schemas and tables in the catalog inherit them.

<StepImage src="/img/uc-assets-ownership/13.png" alt="Catalog permissions tab listing the granted privileges" />

</Step>

</StepGuide>

Repeat these steps for each schema whose owner you want to change.

## Verify

For each asset, confirm the **Owner** field shows the admin group and the **Permissions** tab lists the grants you added.

## Where people trip

<details>
<summary>Cannot see external locations or credentials</summary>

You have to be a member of the metastore admin group to see these assets.
Ask a current metastore admin to add you, or check your membership in the account console.
</details>

<details>
<summary>Cannot change ownership of an asset</summary>

Only the current owner or a metastore admin can transfer ownership.
If the current owner no longer has access, a metastore admin can reassign it.
</details>
